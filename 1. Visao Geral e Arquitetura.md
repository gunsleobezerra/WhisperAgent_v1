# 🎙️ WisperAgent - AI Copilot

## 💡 O Conceito
Um copiloto de IA em tempo real que atua como um assistente de contexto instantâneo. Ele escuta o áudio, transcreve e utiliza modelos de linguagem para processar a informação, sempre seguindo uma **Persona** customizada pelo usuário.

## ⚙️ Funcionalidades Principais
- **Captura de Áudio:** Escuta a entrada (microfone) e/ou a saída de som do sistema (loopback).
- **Transcrição Local (STT):** Transforma voz em texto de forma **100% local**, garantindo máxima privacidade (ninguém além de você tem acesso ao áudio puro) e zero custos de transcrição.
- **Processamento BYOK & APIs Customizadas:** Conecta-se tanto a provedores consolidados (OpenAI, Anthropic Claude, Google Gemini, Groq, DeepSeek) quanto a **qualquer endpoint customizado** compatível com OpenAI (Ollama local, LM Studio, vLLM, OpenRouter ou servidores privados).
- **Personas Customizáveis:** O usuário define como a IA deve agir. Pode ser um "Oráculo de estudos", um "Tático de e-Sports", ou um "Revisor de código sênior".
- **Modo Invisível (Anti-Capture Multiplataforma):** O app funciona como um *overlay* na tela imune a gravações/telas compartilhadas (Discord, Meet, OBS):
  - **Windows:** API `SetWindowDisplayAffinity` (`WDA_EXCLUDEFROMCAPTURE`).
  - **macOS:** API nativa `NSWindow.sharingType = .none` (`NSWindowSharingNone`).
  - **Linux:** Suporte via propriedades de janela X11 / isolamento natural em compositores Wayland.

## 🛠️ Arquitetura Tecnológica Definida

**A fundação do projeto será baseada no ecossistema Tauri (Rust + React).**

- **Detalhes Completos:** [[2. Interface e Overlay]]
- **Frontend (UI):** Desenvolvido em **React** (com Tailwind CSS) para uma interface reativa.
- **Backend (Core):** Construído em **Rust**, orquestrado pelo framework **Tauri**.

### 2. Motor de STT (Speech-to-Text Local)
- **Detalhes Completos:** [[3. Motor STT Local e Audio]]
- Integraremos o modelo Whisper nativamente via Rust (`whisper.cpp`) para garantir que tudo ocorra 100% offline.

### 3. Gerenciamento BYOK, LLMs e Personas
- **Detalhes Completos:** [[4. Integracao LLM e Personas]]
- A aplicação gerencia suas chaves em segurança e opera com arquitetura agêntica e tool calling.

### 4. Otimização de Memória em Tempo Real
- **Detalhes Completos:** [[5. Otimizacao de Memoria e Contexto]]
- Implementação nativa em Rust inspirada no Mem0/Zep (Ring Buffer em RAM + Rolling Summarization com SQLite embutido).
