# 🗺️ Roadmap de Implementação (Passo a Passo)

Este checklist define a ordem exata de desenvolvimento do WisperAgent. Cada etapa está atrelada às suas respectivas Specs granulares.

## Fase 1: Fundação Tauri & Infraestrutura
- [ ] Inicializar projeto: `cargo create-tauri-app` (Rust + React + Vite + TypeScript + Tailwind).
- [ ] Instalar dependências base no `Cargo.toml` (`cpal`, `whisper-rs`, `tokio`, `rusqlite`, `reqwest`).
- [ ] Configurar `tauri.conf.json`:
  - Janela `main` (oculta, Settings).
  - Janela `overlay` (alwaysOnTop, sem bordas, transparente).
  - 🔗 Referência: [[Spec_Tauri_Infrastructure]]
- [ ] Configurar o **System Tray** em Rust (Atalhos: Mute, Settings, Quit).
  - 🔗 Referência: [[Spec_System_Tray]]

## Fase 2: Captura de Áudio & STT (Rust)
- [ ] Implementar Captura de Áudio (`cpal`):
  - [ ] Listagem de dispositivos de áudio.
  - [ ] Hot-swapping e Device Watcher (recair para microfone padrão se falhar).
  - 🔗 Referência: [[Spec_Audio_Capture]]
- [ ] Implementar Motor Whisper (`whisper-rs`):
  - [ ] Rotina de download do modelo `ggml-base.bin` no primeiro boot.
  - [ ] Pipeline de transcrição de áudio f32 para texto.
  - 🔗 Referência: [[Spec_Whisper_Engine]]

## Fase 3: Frontend & Overlays (React)
- [ ] Configurar Roteador Dinâmico no `App.tsx` (exibe Settings vs Overlay baseado em query params).
  - 🔗 Referência: [[Spec_App_Router]]
- [ ] Janela de Overlay (`Live_Overlay`):
  - [ ] Ouvir evento Tauri `stt_transcription_update`.
  - [ ] Implementar Batching UI (atualizar DOM a cada 100ms para poupar CPU).
  - 🔗 Referência: [[Spec_Live_Overlay]]
- [ ] Janela de Settings:
  - [ ] Seletores de Áudio, Modelo, Provider LLM e Monitor Alvo.
  - 🔗 Referência: [[Spec_Settings_Window]]
- [ ] Sistema de Popups & Tool UI:
  - [ ] Escutar eventos de respostas curtas do LLM e renderizar Popups.
  - 🔗 Referência: [[Spec_Popup_System]]

## Fase 4: Cérebro do Agente (LLM & Tools)
- [ ] Cliente BYOK (`Reqwest`):
  - [ ] Requisições HTTP para a API OpenAI-Compatible (roteador).
  - [ ] Tratamento de Streaming (SSE).
  - 🔗 Referência: [[Spec_LLM_Client_BYOK]]
- [ ] Tool Registry & Dual-Mode Invoker:
  - [ ] Parser para Native JSON Tools e Fallback ReAct (XML tags).
  - [ ] Sistema de Aprovação Humana (Human-in-the-loop) disparando eventos para o React.
  - 🔗 Referência: [[Spec_Tool_Registry]]

## Fase 5: Memória & Contexto
- [ ] Hot Ring Buffer (RAM):
  - [ ] Estrutura circular mantendo os últimos 60s de áudio transcrito na thread.
  - 🔗 Referência: [[Spec_Ring_Buffer]]
- [ ] Banco de Dados (SQLite):
  - [ ] Tabela de Resumos (Rolling Summarization).
  - [ ] Worker que condensa a memória RAM a cada pausa na fala e salva no disco.
  - 🔗 Referência: [[Spec_DB_Schema]]
