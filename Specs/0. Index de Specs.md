## Diretrizes Atendidas nestas Specs Granulares:
- [x] **Hot-Swapping**: `[[Spec_Audio_Capture]]` prevê fallbacks de captura.
- [x] **Download do Whisper no 1º Uso**: `[[Spec_Whisper_Engine]]` detalha a rota `init_whisper_engine` e fallback de rede.
- [x] **Otimização de Gargalo de CPU (Batching)**: `[[Spec_Live_Overlay]]` detalha o `stt_transcription_update` a cada 100ms.
- [x] **Aprovação Manual de Ferramentas (Human-in-the-Loop)**: `[[Spec_Popup_System]]` e `[[Spec_Tool_Registry]]` detalham as tags e eventos IPC.

> **Dica SDD:** Todas as Specs acima descrevem exclusivamente **"O Quê"** (rotas, JSONs de payload, códigos de erro) e não **"Como"** (quais laços `for` ou bibliotecas internas o desenvolvedor usará).
